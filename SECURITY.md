# Security policy

Report suspected vulnerabilities privately to [support@proso.com.br](mailto:support@proso.com.br)
with the subject “Proso security report”. Do not open a public issue containing
vulnerability details, API keys, tokens, private page content, or personal data.

Include the affected version, installation source, reproduction steps, potential
impact, and a minimal sanitized example. The maintainer will coordinate next
steps privately. No fixed response time or older-version support window is promised.
