# Getting help with Proso

Install the published extension from [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/proso/).
Audio requires a provider API key, a synthesis host you operate, or an eligible
managed plan. Provider usage may cost money even when Proso itself is free to install.

For bugs and feature requests, use [GitHub Issues](https://github.com/phsb5321/Proso/issues).
Include Firefox and Proso versions, installation source, audio route, reproduction
steps, expected behavior, and actual behavior. Remove API keys, license keys,
personal page content, and other private data from attachments.

For account or payment questions, use [support@proso.com.br](mailto:support@proso.com.br),
the support address published in the Terms of Service. Do not post payment details
in public issues. Commercial licensing inquiries go to
[commercial@proso.com.br](mailto:commercial@proso.com.br).

Donation options are being configured. Donations do not purchase credits,
subscriptions, or priority support.
