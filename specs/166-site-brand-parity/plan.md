# Feature 166 — Plan

**Branch:** `166-site-brand-parity`
**Date:** 13/08/2026
**Spec:** `specs/166-site-brand-parity/spec.md`

## Summary

One slice: derive the two site identity assets from the canonical pipeline,
then extend the existing brand gate to pin them. No site code changes beyond
the two replaced asset files and no new runtime/build dependency.

## Technical context

- **Runtime:** Node.js ESM scripts (existing pattern), ImageMagick 7 +
  Inkscape 1.4 (already provisioned by `shell.nix` for the brand pipeline).
- **Sources of truth:** `packages/extension/assets/icons/band-16.svg` →
  `icon-32.png` (canonical 32px mark, generated by the existing
  svgo→`@resvg/resvg-js` icon pipeline); `brand/svg/proso-lockup-dark.svg`
  (canonical lockup for dark surfaces — light strokes, viewBox 1210×320).
- **Outputs:** `packages/site/assets/images/favicon.png` (byte-copy of the
  canonical 32px mark), `packages/site/assets/images/og-image.svg` (composed:
  navy `#010616` canvas + canonical lockup geometry read from the source
  file), `packages/site/assets/images/og-image.png` (deterministic inkscape
  render of the composition).
- **Gate:** extend `scripts/verify-brand-assets.mjs` with `assertSiteAssets()`:
  favicon byte-identity with `icon-32.png`; og-image.svg structural checks
  (existing `assertSvg`-style rules, palette, no forbidden constructs, no
  `<text>`); og-image.png byte-match against a fresh render; plant fixtures
  for the retired favicon and the pre-rebrand og-image.
- **Renderer:** a small `scripts/render-site-brand-assets.mjs` (mirrors the
  existing `render-brand-proofs.mjs` inkscape/magick helpers) with a `--check`
  mode; the og-image composition is generated by reading
  `brand/svg/proso-lockup-dark.svg` and wrapping its inner geometry — the
  canonical file stays the single source, nothing is re-authored.
- **Site package:** unchanged (`package.json` stays an empty checkout
  configuration; static HTML/CSS/vanilla JS untouched).

## Constitution check

- **Privacy:** PASS — local assets only; no user/page data, no network.
- **Security:** PASS — no executable SVG constructs (gate-enforced), no
  credentials, no permission surface.
- **Modularity:** PASS — reuses the canonical brand pipeline; the site package
  gains no build step.
- **Test coverage:** PASS — deterministic gate + plant fixtures + browser
  receipts.

## Risk register

| Risk | Impact | Mitigation |
|---|---|---|
| inkscape render non-deterministic across versions | gate flakes red | `--check` mode re-renders with the pinned inkscape from shell.nix; byte-match compared against the committed PNG; failure names the renderer |
| Lockup geometry drift breaks the composition | stale og-image ships | the composer reads `proso-lockup-dark.svg` at render time; verify re-runs the composer in `--check` and byte-compares — drift turns the gate red |
| Favicon/canonical-icon divergence | tab favicon ≠ toolbar mark | byte-identity check, not visual similarity |
| `<text>` reintroduced in og-image | font dependency returns | structural gate forbids `text`/`font`/`image`/`filter` constructs |
