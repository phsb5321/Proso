# Implementation Plan: Hexagonal Wiring Recovery

**Branch**: `062-hexagonal-wiring-recovery` | **Date**: 2026-02-08 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/062-hexagonal-wiring-recovery/spec.md`

## Summary

The hexagonal architecture migration (034-061) registered 86 message handlers across 15 files but never wired the dependency injection needed for 5 of 6 handler subsystems. Additionally, message format mismatches between adapters and content scripts, a stale reference pattern in provider switching, a Browser TTS timing/caching bug, and incorrect popup message types combine to render the extension completely non-functional at runtime. This plan fixes all 18+ bugs in 6 surgical phases with no architectural changes.
