# Quickstart: Complete Architecture Migration

**Feature**: 061-complete-architecture-migration
**Date**: 2026-02-08

## Prerequisites

- Node.js 18+
- pnpm 10.29+
- `firefox-nightly` in PATH (NixOS: already configured in wxt.config.ts)

## Setup

```bash
git checkout 061-complete-architecture-migration
pnpm install
```

## Development

```bash
# Start dev server (opens Firefox with extension loaded)
pnpm run dev

# Build production
pnpm run build:firefox

# Run tests
pnpm test

# Run quality checks
pnpm run quality
```

## Manual Testing Workflow

### Test 1: Core Playback (P1)
1. `pnpm run dev` → Firefox opens
2. Navigate to any article (e.g., Wikipedia)
3. Click VoxPage icon → Press Play
4. **Expected**: Audio plays within 5 seconds, no console errors
5. Test Pause, Resume, Next, Previous, Stop

### Test 2: Visual Feedback (P1)
1. Start playback on a multi-paragraph article
2. **Expected**: Current paragraph highlighted on page
3. **Expected**: Sticky footer appears at bottom
4. **Expected**: Footer controls work (play/pause/skip)
5. **Expected**: Popup shows "Playing" with paragraph count

### Test 3: Provider Switch (P2)
1. Open settings → Switch to ElevenLabs (enter API key)
2. Play a page
3. **Expected**: Audio generated by ElevenLabs (different voice quality)
4. Switch speed to 1.5x → **Expected**: Next paragraph plays faster

### Test 4: Cache (P2)
1. Play a full page
2. Stop → Play same page again
3. **Expected**: Second playback starts faster (cached audio)

### Test 5: Console Cleanliness (P3)
1. Open browser console (`Ctrl+Shift+J`)
2. Use all features
3. **Expected**: Zero "Unknown message type" warnings
4. **Expected**: Zero "Invalid URI" errors

## Architecture Reference

```
src/
├── core/           # Pure domain logic (PlaybackState, PlaybackService)
├── ports/          # Interface contracts (IAudioGenerator, IHighlightSynchronizer)
├── adapters/       # Implementations (BrowserTtsAudioAdapter, HighlightSyncAdapter)
├── composition/    # DI container (wires adapters to services)
├── handlers/       # Message handler registry (16 domains)
├── entrypoints/    # WXT entry points (background, content, popup, options)
└── utils/          # Shared utilities (cache, config, messaging, telemetry)
```
